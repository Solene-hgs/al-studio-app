# AL STUDIO

Prototype d'application mobile de dressing intelligent inspiré du wireframe fourni.

## Aperçu

Cette version est une maquette interactive web (mobile-first) de la home page AL STUDIO, avec :
- un header avec heure + météo,
- un look du jour,
- un calendrier simplifié,
- un bouton d'ajout de vêtement,
- des filtres de style,
- des interactions légères (sélection de filtres, favoris, jours du calendrier).

## Lancer localement

### Option 1 - simple navigateur
Ouvrez directement `index.html` dans votre navigateur.

### Option 2 - serveur local rapide
```bash
python3 -m http.server 8000
```
Puis ouvrez : http://localhost:8000

## Structure
- `index.html` : interface de l'application
- `styles.css` : design mobile-first
- `app.js` : interactions et logique légère

## À noter
Cette maquette est pensée comme un prototype de démonstration. Elle peut ensuite être convertie en React Native / Expo ou Flutter pour un vrai app mobile.
